## ADDED Requirements

### Requirement: 同一解析目的只允许一份实现

对同一种外部数据格式的解析，全仓 MUST 只有一份实现。MUST NOT 因两条链路各自演进而出现两套解析。

理由：实测 bq CSV 解析曾同时存在正确实现（Python `csv.reader`）与错误实现（`awk -F,`），修复其中一处后另一处继续把「1 个事件」渲染成「11」。⚠️ 重复定义检测只覆盖同名函数，改了名的重复无工具可抓。

#### Scenario: 新增需要解析同类数据的代码路径

- **WHEN** 新代码需要解析已有共享实现所覆盖的格式
- **THEN** MUST 复用该实现
- **AND** MUST NOT 新写一份，即使调用形态不同

### Requirement: SQL 模板的占位符替换必须收口且缺项即失败

SQL 模板的占位符替换 MUST 由单一入口完成。渲染后仍存在未替换占位符时 MUST 当场失败并指出文件与占位符名，MUST NOT 将其提交给数据源执行。

理由：未替换的占位符提交后表现为数据源语法错——错误信息不含「哪个占位符漏了」，而这正是「新增占位符只改了一条链路」的典型表现。

#### Scenario: 新增占位符后只改了一条链路

- **WHEN** SQL 模板新增占位符，而某条调用链路未同步传值
- **THEN** 该链路 MUST 在渲染时失败并指名缺失的占位符
- **AND** MUST NOT 等到查询执行时才暴露

#### Scenario: 替换值含分隔符或元字符

- **WHEN** 替换值包含流编辑器的分隔符或特殊含义字符
- **THEN** 替换结果 MUST 与字面值一致，MUST NOT 被静默改写

### Requirement: 共享取数层不得为窗口设默认值

跨链路共享的取数辅助 MUST 要求调用方显式提供时间窗口，MUST NOT 提供默认值。

理由：两条链路的窗口不同（日报的崩溃窗与性能窗不同、周报另有其窗）。默认值会让漏传的一方静默使用错误窗口——数字不报错且看起来合理。

#### Scenario: 调用方漏传窗口

- **WHEN** 调用方未提供窗口天数
- **THEN** MUST 失败，MUST NOT 回落到任何默认窗口
