## ADDED Requirements

### Requirement: 维度呈现优先直达而非静态复刻

影响面维度的呈现 MUST 限于可定位对象与集中度判读所需，MUST NOT 以静态表格复刻数据源控制台已提供的完整分布下钻。

需要完整分布时 MUST 经直达链接交由数据源自身呈现。

理由：静态复刻产生两项成本——篇幅随维度数线性增长，以及每张表都必须解释其口径为何与控制台不同。实测同一条 issue 在台账、周报两段、日报中给出 7 / 4 / 2 / 1 四个数字，四者按各自口径均正确，但读者需要四段注解才能判读；数据源控制台上它是一个数字加一个筛选控件。

#### Scenario: 维度分布可在控制台获得

- **WHEN** 某维度的完整分布可经数据源控制台按同一 issue 直接查看
- **THEN** 报告 MUST 只给可定位对象与集中度
- **AND** MUST 提供直达链接
- **AND** MUST NOT 复刻完整分布表

#### Scenario: 控制台无法提供的维度

- **WHEN** 某维度是数据源控制台不提供的（跨轮次变化、跨版本生命周期、崩溃与性能并排）
- **THEN** MUST 在报告中完整呈现
- **AND** 理由：这类内容是报告相对控制台的唯一增量

#### Scenario: 口径差异注解的存废

- **WHEN** 某条注解的唯一作用是解释本报告口径与控制台口径的差异
- **THEN** 该维度改为直达后 MUST 一并移除该注解
- **AND** MUST NOT 保留已无对照对象的对照警告
