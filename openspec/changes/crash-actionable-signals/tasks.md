- [x] 2.3 三态判定：新增（不在基准）/ 回归（在基准但末次日期早于上一轮）/ 长期（末次日期即上一轮）

- [x] 2.7 卡片：若本轮有新增或回归，在影响集中那块加一句摘要（不新增表格行）
