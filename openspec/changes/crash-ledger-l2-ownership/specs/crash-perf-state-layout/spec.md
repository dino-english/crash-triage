## Purpose

定义运行数据目录的分层组织与保留策略，以及仓库内产出物的保留判据。目标是让跑批产物可按日期定位、基准文件零迁移风险、仓库只承载代码与不可再生的坐标。

## ADDED Requirements

### Requirement: 跑批产物按日期与链路分组

每次跑批的中间产物 MUST 归入以日期与链路标识组织的目录，同日多次跑批以时刻区分。

#### Scenario: L1 跑批产生中间产物

- **WHEN** L1 跑批产生指标中间文件与快照
- **THEN** 这些文件落在该日期下的 L1 分组内
- **AND** 同日再次跑批不覆盖前一次的产物

#### Scenario: 排查最近一次跑批

- **WHEN** 需要查看某日最近一次跑批的产物
- **THEN** 可不经时间戳直接定位到该次产物

#### Scenario: 跑批未产生任何产物

- **WHEN** 跑批在产生产物前失败
- **THEN** 不遗留空目录

### Requirement: 基准文件独立于跑批分组

跨跑批累积的基准文件 MUST NOT 按日期分组存放， MUST 保持稳定位置。

#### Scenario: 跑批产物按期清理

- **WHEN** 过期跑批产物被清理
- **THEN** 文档台账、目录缓存、变化检测基准、指标历史、健康状态均不受影响

#### Scenario: 基准文件缺失

- **WHEN** 变化检测基准不存在
- **THEN** 只建立基线不报变化
- **AND** 不把全部条目报为新增

### Requirement: 跑批产物定期清理

跑批产物 MUST 有明确保留期，超期自动清理。

#### Scenario: 产物超出保留期

- **WHEN** 某日期的跑批产物超出保留期
- **THEN** 该日期分组被整体清理

#### Scenario: 事实层与台账不参与清理

- **WHEN** 清理执行
- **THEN** 事实层记录与台账本地源不被删除

### Requirement: 仓库只保留不可再生的坐标

代码仓库中 MUST NOT 保留可再生的运行产出物；仅保留无法从其他来源重建的数据。

#### Scenario: 判定某产出物是否入库

- **WHEN** 某产出物可由重跑流水线再生
- **THEN** 该产出物不入库，存放于运行数据目录

#### Scenario: 报告归档索引

- **WHEN** 归档记录存有历次投递文档的地址
- **AND** 该地址无法从投递目标端枚举重建
- **THEN** 该归档保留在仓库中并纳入版本管理

#### Scenario: 台账与专项快照

- **WHEN** 台账与历史专项快照存在于仓库
- **THEN** 移出仓库，存放于运行数据目录
