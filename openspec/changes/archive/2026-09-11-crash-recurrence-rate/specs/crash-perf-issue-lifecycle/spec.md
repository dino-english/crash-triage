## ADDED Requirements

### Requirement: 复发数以分数呈现且三态可区分

周报 MUST 呈现本轮回归 issue 数与本轮 issue 总数的分数，MUST NOT 单独呈现百分比。

理由：基准规模实测仅 14 项，1 个回归 = 7.1%、2 个 = 14.3%——百分比在此分母上是伪精度，且周与周之间的跳动会被读成趋势。

#### Scenario: 基准尚未建立

- **WHEN** 生命周期基准为空
- **THEN** MUST 说明「本轮建立基准」
- **AND** MUST NOT 呈现 `0 / 0` 或 `0%`——那会让「没有回归」与「还算不了」无法区分

#### Scenario: 本轮无回归

- **WHEN** 基准已建立且无 issue 回归
- **THEN** MUST 呈现带分母的 `0 / N`

#### Scenario: 判定时序

- **WHEN** 判定「基准是否已建立」
- **THEN** MUST 在基准被本轮值覆盖**之前**判定
- **AND** 理由：跑批收尾会把基准刷成本轮值，之后再判永远是「已建立」
