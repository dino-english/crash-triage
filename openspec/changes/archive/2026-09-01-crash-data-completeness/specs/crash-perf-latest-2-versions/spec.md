## ADDED Requirements

### Requirement: 性能段按数据可得性独立选版

性能段 SHALL 可以使用与崩溃段、放量段**不同的版本列**：按版本号降序逐个检查该版本在性能窗口内是否有数据，凑满所需列数即停。

⛔ 判据 MUST 只看「该版本在性能窗口内有没有数据」，MUST NOT 引入任何形式的会话量门槛——把会话量门槛以等价手段绕回来是明确禁止的（`MIN_SESSIONS` 中和为 1 是有实测依据的既有决定）。

⛔ 崩溃段与放量段的选版口径 MUST NOT 改变：最新版本仍照常出现在这两段，「让新版本被看见」的原则完整保留。性能段换列的前提正是**它在那里本来就没有任何数据可看**。

#### Scenario: 最新版在性能表内无数据

- **WHEN** 最新版本在性能窗口内 0 行，而更旧的版本有数据
- **THEN** 性能段 MAY 增加一列展示有数据的旧版本
- **AND** 该列 MUST 带角标显式标注它是因性能数据可得性而加入的
- **AND** 最新版本 MUST 仍出现在崩溃段与放量段

#### Scenario: 回溯有上限

- **WHEN** 逐个回溯候选版本
- **THEN** 候选总数 MUST 有上限（默认最新 2 版 + 回溯 2 版 = 4 个候选）
- **AND** 候选全部无数据时 MUST 停止回溯并转既有「数据未同步」口径的告警，MUST NOT 继续翻到更旧的版本

#### Scenario: 补充列的理由必须逐列说明

- **WHEN** 版本列里出现最新版本之外的补充列
- **THEN** 摘要 MUST 分别说明每一列的加入理由（主力 / 性能兜底）
- **AND** MUST NOT 把因性能可得性加入的列一律称作「主力」——该版本的会话量可能很小

## MODIFIED Requirements

### Requirement: 版本无数据与数据未同步严格区分

数据缺失 SHALL 按三态判定并分别呈现，判定顺序 MUST 为：表不存在 → 表整体无数据 → 该版本无数据。

第 3 态内部 SHALL 再分两种子情况（下称「第 3 态细分」）。⛔ 细分 MUST NOT 改变前两态的判据、顺序与文案，也 MUST NOT 引入第 4 态。

#### Scenario: 表整体无数据判定不带版本过滤

- **WHEN** 判定某表是否「数据未同步」
- **THEN** MUST 使用不带版本过滤的探测
- **AND** MUST NOT 用版本过滤后的 0 行推断数据源故障

#### Scenario: 该版本无数据

- **WHEN** 表在窗口内有数据但目标版本 0 行
- **THEN** MUST 呈现为「该版本无数据」
- **AND** MUST NOT 呈现为「数据未同步」或数值 0

#### Scenario: 新版在性能段常态无数据

- **WHEN** 最新版本在滞后的性能批量表中尚无数据
- **THEN** 性能列 MUST 显示该版本自己的缺数状态且 MUST NOT 触发告警
- **AND** MUST NOT 把更旧版本的数值填进该版本的格子充数
- **AND** 另起一列展示有数据的旧版本是允许的，见「性能段按数据可得性独立选版」

#### Scenario: 第 3 态细分——尚无数据

- **WHEN** 该版本该指标在历史中从未有过非 null 值
- **THEN** MUST 呈现为「尚无数据」，属数据源滞后的正常表现
- **AND** 仅当能确证数据即将到位时（该版本在尚未完整的当日已有行）MAY 给出预计到位日期
- **AND** 无法确证时 MUST NOT 给出预计日期——不兑现的承诺比不说更糟

#### Scenario: 第 3 态细分——本轮未取到

- **WHEN** 该版本历史中曾有非 null 值，但本轮为空
- **THEN** MUST 呈现为「本轮未取到」并与「尚无数据」用不同文案区分，属取数故障或导出退化
- **AND** 文案 MUST 带上「上次有值」的日期——不带日期时连续多轮失败会一直显示同一句话，看不出已经僵住
- **AND** MUST NOT 把历史值搬进本轮的格子：两侧口径不同（滚动窗口 vs 单日、最差页 vs 平台级聚合、窗口 top-N vs 全量）

#### Scenario: 缺失判据必须显式判 null

- **WHEN** 判定某指标本轮是否有值
- **THEN** MUST 显式判定 `null`
- **AND** MUST NOT 使用真值性判断——慢帧率、冻结率、接口错误率的 `0` 是合法且常见的取值，当成缺失会把「今天确实取到了 0」渲染成故障
